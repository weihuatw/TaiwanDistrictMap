# 兒少保護與教保地圖

入口 `#/child-safety`。地圖著色與行政區清單使用 2024、2025 全年 22 縣市統計。URL 的 `year` 與 `metric=reports|rate|abused` 可分享，行政區路徑止於縣市。預設顯示最新完整年度的通報件次。

## 來源與計算

- [衛福部社會福利公務統計 3.5.1、3.5.6](https://dep.mohw.gov.tw/DOS/cp-5337-62357-113.html)提供縣市年度彙總。3.5.1 主圖層採兒少保護通報表的件次，社會安全網諮詢通報及兩種通報表單的分流另列。通報可含重複、歷史及跨轄案件。3.5.6 採經調查後獲後續保護服務的受虐兒少人數。
- [戶政司 ODRP014](https://data.gov.tw/dataset/77132)以當年度 12 月底單一年齡人口逐村加總 0–17 歲人數至縣市，包含來源中有戶籍人口但缺對應村里圖形的資料。標準化件次＝通報件次 ÷ 年底 0–17 歲戶籍人口 × 10,000。全臺以總件次及總人口計算。此指標呈現以人口規模標準化的通報量。
- [教育部全國教保裁罰原表](https://crc.sfaa.gov.tw/Uploadfile/Statiscs/80_20260907145217_7155105.pdf)提供 2018–2025 年按類型的受裁罰人數。官方試算表只有全國統計，2023 年 3 月起適用範圍有變動。
- [教育部幼兒園名錄](https://data.gov.tw/dataset/6086)收錄最新可用學年度 114 年的 6,747 所幼兒園。選取縣市並展開名錄後才讀取分片，可依鄉鎮及園所查看地址。官方名錄只有地址，裁罰查詢連往[全國教保資訊網](https://ap.ece.moe.edu.tw/webecems/punishSearch.aspx)。

## 更新與驗證

```sh
npm run child-safety:fetch
npm run child-safety:build
npm run child-safety:check
```

原始檔留在忽略提交的 `data/raw/child-safety/`。公開統計摘要記錄來源 URL 與 SHA-256，名錄按縣市分片。更新年度時先確認表格口徑、人口年月、API 分頁數及官方合計，再修改腳本年度與核對值。檢查僅讀公開資料，驗證 22 縣市覆蓋、全臺合計、分流加總與園所代碼、行政區對照。此版未使用兒少保護逐案資料。

## 園所裁罰公告

官方查詢提供按縣市的 WebForms 分頁。下載器保留每次查詢的表單狀態與 cookie，從第一頁讀到「下一頁」停用，再逐園讀取裁罰明細及官方園址座標。園所名稱採官方查詢結果，處分時名稱另存，包含查詢中仍可見的停辦或其他狀態園所。快照只代表取得當時公開的公告範圍，公告期限及後續更正會影響可見資料。

```sh
npm run child-safety:sanctions:fetch
npm run child-safety:build
npm run child-safety:check
```

原始快照位於忽略提交的 `data/raw/child-safety/sanctions/`。公開 `sanctions.json` 是全臺園所座標、筆數與取得日期索引，`sanctions/{COUNTYCODE}.json` 在選取縣市並展開裁罰紀錄時載入，含官方查詢網址、來源 SHA-256 與全部裁罰列。快照中的園所識別碼由縣市、目前名稱及地址產生，與學年度名錄的官方學校代碼分開。

地圖預設顯示裁罰園所標記，圓點內數字為公開裁罰紀錄筆數。可隱藏標記，按鄉鎮及園所查閱處分日期、當時園名、文號、依據、違反規定、負責人／行為人與處分內容。相同園所的多張處分書逐列保存。各筆採官方原文，主題不自行推定行政違規是否屬虐待。

只使用官方園址座標並核對是否落在公告所屬鄉鎮。缺座標或座標與鄉鎮不符時保留完整清單及裁罰資料，`positionStatus` 記錄原因，標記不顯示該位置。檢查腳本核對 22 縣市、分頁完成狀態、索引與分片筆數、官方明細來源及定位行政區。URL 的 `school` 可還原園所，`markers=false` 隱藏園所標記。

官方明細與地圖頁依賴查詢 session，擷取時的明細網址留存於原始快照供稽核。介面直接顯示已收錄的裁罰全文，外部連結採官方查詢入口。

2026-11-11 取得快照共 22 縣市、104 頁查詢結果、913 所園所與 1,738 筆裁罰紀錄。886 所座標可核對，18 所無可用座標、9 所座標與公告鄉鎮不符；全部 913 所均可由縣市清單查閱。
