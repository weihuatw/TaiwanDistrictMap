# 桌面雙地圖比較

桌面寬度大於 760px 時，底部中央的「地圖比較」浮動按鈕可展開單一／雙地圖、左右主題、保持同步與顯示資訊卡設定，不再保留占用地圖高度的頂部 bar。面板預設關閉，點外部、焦點離開、關閉按鈕或 Escape 可收起；關閉按鈕與 Escape 會把焦點還給入口，設定值保留。雙圖時入口顯示同步／獨立狀態，兩側保留主題標示，即使隱藏資訊卡也可辨識。面板展開／收起不改變地圖尺寸或視角。

雙地圖預設各占 50%，分隔線支援 pointer capture 拖曳、左右方向鍵、Home／End，雙擊恢復等寬；可調範圍為 25–75%。handle 外觀為 16×48px，分隔線保留 10px 命中範圍及 handle 本身的命中區域。主題的指標、年份、族群、學制與學區著色各自獨立。隱藏資訊卡會同時隱藏兩側位置／統計面板、所選區域卡與房價成交清單，圖例和地圖工具繼續可用。

手機不提供比較設定，也不建立第二張地圖。桌面雙地圖縮到手機時，會銷毀右側應用、marker、事件與 router，恢復資訊面板；回到桌面仍是單一地圖，可再開啟雙地圖。

## 實作責任

- `src/comparison/workspace.ts` 組合兩個獨立應用、主題載入器、桌面設定、尺寸更新與清理。各主題只額外提供 map getter。
- 左側沿用 `HashRouter` 與瀏覽器每層歷史；右側 `createLocalRouter()` 使用相同歷史規則，但歷史完全在記憶體內。瀏覽器返回／前進操作左側，啟用同步時由左側主導同步還原。
- `src/comparison/sync.ts` 同步地理選取與相機，不同步主題或篩選。最後收到 pointer／wheel／keyboard 操作的一側主導相機；同步套用相機期間設有重入鎖，接收側 move 不會回傳。同步導覽另記錄待提交路徑，資料晚到、或使用者已在另一側平移時，也不把同步提交再回送。
- 同步另外保存完整地理選取。操作鄉鎮粒度地圖的相機或切換密度指標，不會因此清除另一側村里選取；明確選區或返回才更新共同地理選取。較新的導覽仍沿用各 navigator 的請求序號。
- 應用與地圖容器採 pane 內定位。shell／主題使用 `data-ui` 作區域內查詢與 CSS selector，DOM ID、label／ARIA 引用與 radio name 依 pane 區隔，兩個相同主題也能獨立操作。Escape 僅作用於目前操作的 pane。
- 拖曳分隔線透過 `map.resize({ preserveViewport: true })` 更新 canvas；共用圖層辨識此事件後不重新 fit，保留使用者平移及同步相機。一般 resize 的既有取景行為保留。標籤仍在相機停止後排程。

## 粒度與同範圍評估

資料粒度與相機可獨立處理。房價與人口密度仍只選取鄉鎮，學區從一般地區路徑只接收到鄉鎮；另一側進入村里時，它們可以繼續放大、平移至該村里位置，但呈現鄉鎮資料及鄉鎮界線，不產生或估算村里數值。畫面會註明「此主題資料止於鄉鎮市區；視角仍與另一側同步」。學校 ID 僅在兩側皆為學區時同步；轉到其他主題時只轉行政區祖先。

實作採相同 center、zoom、bearing、pitch，以 `jumpTo()` 即時跟隨；資料及 style 晚到時再套用主導側目前相機。這與 MapLibre 的 [Map 相機／resize API](https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/) 及 [JumpToOptions](https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/JumpToOptions/) 相符。實測村里行政區與鄉鎮房價／密度可以保持相同中心及比例尺，無需下載另一層統計。

左右等寬時可見地理範圍一致；分隔線造成不同寬度時，保持相同中心與比例尺，可見東西範圍自然不同。若改成各自 `fitBounds()` 容納完全相同 bounds，兩側比例尺可能不同、而且長寬比仍使實際可見 bounds 不完全相等；因此目前保留相同相機，適合對照同一位置。這是從 viewport 長寬比與上述相機 API 推得的取捨。

比較設定及右側狀態不寫進 URL；重新整理回到左側單一地圖。兩側「複製分享」各自分享該主題與地區的正常網址。

## 本機驗證（2026-10-12）

- `npm test`：154 個 Node 測試、18 個 Python 測試通過。新增比較測試涵蓋雙向同步與重入、關閉同步、延遲提交、密度正規化、學校 ID、query 保留與右側歷史；圖層測試涵蓋分隔 resize 不重新 fit。
- CUA 1280px 桌面：雙圖、左右主題切換、縣市／鄉鎮／村里選取、右側搜尋選里、地圖灰色鄰里點擊（西村里 → 正和里）、反向同步、瀏覽器返回、兩側平移／縮放、拖曳及方向鍵調整、關閉同步後獨立縮放、資訊卡一起隱藏／顯示。
- 兩個學區主題：左右著色 radio 各自獨立、選校同步，DOM ID 無重複。
- 村里行政區與鄉鎮房價／密度並列：保留村里選取、鄉鎮數值與相同視角。
- 正式 `/TaiwanDistrictMap/` base 建置成功；本機每個資料回應延遲 300ms，未快取縣市連續選取（嘉義縣 → 南投縣）與鄉鎮載入期間回首頁，兩側最後均保留最新選取。原住民主題初始化／路由 manifest 晚到時另有生命週期及請求序號保護。
- 390×844 手機：桌面切到手機後只剩一張 map、比較設定消失、資訊面板恢復；另回歸所得面板收折／inert／Enter 展開與學校搜尋。
