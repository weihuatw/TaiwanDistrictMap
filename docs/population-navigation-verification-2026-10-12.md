# 人口主題與跨主題切換驗證

日期：2026-10-12（臺北時間）。本機以 `/TaiwanDistrictMap/` base 建置並驗證，沒有進行公開站部署。

## 自動檢查

- `npm test`：130 個 Node 測試、14 個 Python 測試通過。
- 行政區、所得、學區、房價、人口與政治六種資料檢查全部通過。
- `npm run build -- --base /TaiwanDistrictMap/` 成功；保留既有大型共享 bundle 提示。
- 人口檢查核對 7,781 筆來源、7,780 個具名界線、206 個未編定範圍，新增三組年齡人數均與單一年齡及各層加總一致。
- 新增回歸涵蓋跨主題行政區轉換、學校 ID 隔離、各主題 query、相機保存／消耗、跨祖先競態、載入中切換、人口指標分母、零人口與缺漏、錯誤摘要拒絕及重試。

## 瀏覽器驗證

使用 Codex CUA，在實際確認的桌面 1280×900 與手機 390×844 進行測試。

- 西村里行政區概覽展開人口卡，可直接開啟同里人口主題；自行放大後切到人口及所得，比例尺保持 50 公尺。
- 同里五種人口指標：4,092 人、1,807 戶、高齡 29.5%、幼年 12.0%、女性 54.7%；切換時保持地區與比例尺。
- 離開再回人口主題保留高齡指標。房價切到學區仍保留信義區，房價 2024 年篩選亦保留在返回連結。
- 選取博愛國小後切到政治主題，目的路由為信義區，不含學校 ID。
- 人口深層連結可直接還原指標。清單搜尋西村里後換指標，仍為 1／41 筆；選里後瀏覽器返回信義區，保持高齡指標。
- 點選地圖灰色大安區後，路由、村里清單與人口摘要同步切到大安區。
- 手機首次畫面完整顯示地區、指標、主要值與年月；明細與圖例位於可捲動底部面板。收折時資訊區退出無障礙樹，Enter 可重新展開。
- 手機回歸行政區、所得、學區與人口切換，行政區／所得保留村里，學區保留至鄉鎮。
- 受控伺服器將人口摘要延遲並回傳一次 503：分享與初始指標控制維持停用，顯示重試；重試後成功還原西村里與幼年指標。
- 在人口頁仍為載入中、分享停用時切換所得，成功進入板橋區；女性指標保留在返回人口的連結。

## 範圍

本次新增的是位置／視角延續與人口主題，跨主題仍重建 map、各主題 repository 仍獨立。沒有新增人口密度、人口動態來源或歷史月份；沒有將房價統計改為村里層級。瀏覽器驗證採代表地區，未逐一操作所有村里或所有主題／篩選組合。
