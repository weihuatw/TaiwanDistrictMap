# 實價登錄房價地圖

入口：[housing.html](../housing.html)。本機開發先執行 `npm run housing:fetch`、`npm run housing:build`、`npm run housing:check`，再開啟 `http://127.0.0.1:5173/housing.html`。資料更新不屬於一般網站 build；目前不會自動排程或發布。

## 目前範圍

頁面提供 2024／2025 年成屋買賣的縣市與鄉鎮市區統計、可比單價中位數、P25／P75、樣本數與案件明細。預設樣本為主要用途「住家用」的公寓、華廈及住宅大樓；透天可切換檢視。統計按成交日期歸年，使用當前行政區界做對照。

免費官方批次檔沒有經緯度，第一版不顯示成交點、里別價格或學區價格。含完整門牌不表示能推導交易點位。部分交易尚未對應鄉鎮時會列於 `public/data/housing/reports/unresolved.json`，不納入鄉鎮統計。

單價以原始元／平方公尺保存，再換算萬元／坪（1坪 = 400/121 m²）。完整車位總價和面積時，按「總價扣車位價格／建物面積扣車位面積」重算；無法拆分者保留交易原單價供明細檢視，但不納入主中位數。屋型／用途／特殊交易不符合預設時保留案件及排除原因。備註含親友、關係人、共有人、急買急賣、附條件買賣、瑕疵物件、持分交易或特殊交易等明列詞時先標記並排除預設統計；調整詞表須同步版本化及抽查。

中位數及分位數直接由案件單價計算，採線性插值 type 7。樣本少於 10 不顯示價格級距，10 至 29 註記樣本偏少，30 筆以上一般呈現。這些門檻與固定色階（15、25、40、60、80 萬元／坪）是產品設定，不是內政部指標。交易樣本不是該區全部房屋的市場行情。

## 來源及更新

主來源為[內政部地政司不動產成交案件實際資訊 Open Data](https://plvr.land.moi.gov.tw/DownloadOpenData)。`scripts/housing/fetch.py` 使用官方當期及歷史批次 CSV ZIP；預設回填發布季 `112S4` 至最新腳本所列季別並抓當期快照。每批記錄 URL、下載時間、涵蓋文字、byte 數與 SHA-256 到忽略的 `data/raw/housing/`、`data/housing/sources.json`。批次 manifest 發現縣市檔，不把縣市英文字母硬編碼為行政代碼。

目前官方網頁公布日期節奏為每月 1、11、21 日；這是預期更新節奏，不是下載保證。買賣批次內容依登記日期範圍說明，統計則依主檔每筆交易日期。批次快照不保證完整反映後續更正、撤銷或遲報；`manifest.json` 保留下載範圍及限制，不能把下載日期當完整交易截止日期。

每個主檔的中英文說明列與 schema 變化分開檢查。以縣市＋編號作候選案件鍵，跨批次同內容去重；同鍵內容衝突按已記錄批次順位處理並產生衝突報告，不能當成有官方更新序號的真實更正時間。地址只用作明細文字，不以模糊 geocoder 推測座標或村里。授權為[政府資料開放授權條款第1版](https://data.gov.tw/license)，頁面標示提供機關與授權。

資料原始檔與中間檔位於 `.gitignore` 管理的 `data/raw/housing/`。公開成果位於 `public/data/housing/`；重建前先重新下載或保存好來源快照。統計按年度、型態與行政區分檔，案件清單依行政區拆成最多 250 筆一片、以 gzip 壓縮的二進位檔儲存，選區後才載入並在瀏覽器解壓；採中性副檔名可避免靜態伺服器自動解壓後，瀏覽器再重複解壓。`housing:check` 核對縣市與行政區加總、分片筆數及壓縮大小。

## 程式位置

- `src/apps/housing/`：頁面、主題色階、統計卡與成交明細資料載入。
- `scripts/housing/`：官方批次下載、正規化、產生資料及檢查。
- `data/housing/sources.json`：下載 URL、SHA-256 及批次涵蓋範圍。
- `public/data/housing/manifest.json`：頁面使用之資料版本、樣本量與限制。
- `public/data/housing/summary/`、`transactions/`：縣市、行政區與逐筆清單。
- `public/data/housing/reports/`：編號衝突與區碼未對應報告。

未來新增座標前，先核實內政部付費含坐標批次或官方門牌 API 的費用、批次額度、保存期限及地圖展示權；定位要保留精度等級與錯配報告。村里統計須使用可靠門牌／地籍點位與未簡化村里界。學區附近距離查詢應標「附近」；部分鄰學區不能當整里歸屬。
