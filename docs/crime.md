# 刑事統計地圖

入口 `#/crime`，2026-10-13 新增。只發布行政區彙總，不發布案件日期、地址、經緯度或逐案資料，不建立案件點位或 pin。

## 統計範圍與期間

| 範圍 | 地理層級 | 指標 | 2026 截止期間 |
| --- | --- | --- | --- |
| 全般刑案／嫌疑犯 | 全臺、22 縣市警察機關 | 件數、發生率、嫌疑犯人數、犯罪人口率 | 1–8 月 |
| 收錄 8 案類 | 全臺、縣市、368 鄉鎮 | 件數、發生率 | 1–6 月 |

2024、2025 可選全年；三年均可切換「1–6 月」以比較相同期間。2026 不換算成年率。下拉選單的截止月份與資料 manifest 一致，不宣稱截至今天。

全般刑案使用內政部[發生件數按機關別](https://data.gov.tw/dataset/9603)與[嫌疑犯人數按機關別](https://data.gov.tw/dataset/9604)，對應 `c0620101`／`c0620103`。保留全般、竊盜、詐欺背信、傷害、公共危險、毒品、強盜搶奪、妨害性自主等來源實際分類。子分類不是完整案類清單，不將子分類加總代替官方總計。

全臺使用官方機關別總計，包含署所屬機關；其與 22 縣市合計的差額另存 `unassigned['cases:<category>']`／`unassigned['suspects:<category>']` 並顯示。縣市機關資料不是嫌疑犯居住地，不稱為居民犯罪比例。嫌疑犯不是定罪人口，未確認跨案／跨期去重，不宣稱為不同個人的人口占比。

鄉鎮使用警政署[犯罪資料](https://data.gov.tw/dataset/14200)每季初步數：住宅竊盜、汽車竊盜、機車竊盜、強盜、搶奪、毒品、強制性交、組織犯罪防制條例。合計標成「收錄 8 案類合計」，不代表全部刑案，也不從件數推算犯罪人口。來源每列作一筆發生紀錄，完全相同的案類／日期／行政區可以是不同案件，不能以這些欄位去重；季度日期範圍互斥並驗證。

## 人口分母與限制

發生率＝期間件數 ÷ 平均戶籍人口 × 100,000；犯罪人口率＝期間嫌疑犯人數 ÷ 平均戶籍人口 × 100,000。平均人口採前一年年底與期間最後月底的平均。全年重用既有年度人口分片；半年另取 ODRP013 11306、11406、11506，2026 最新期間另取 11508。先加總件數／人口再算率，不平均各鄉鎮的比率。戶籍人口只供比較，不代表居民個人風險。

2024 年系統整合曾造成缺漏，9 月起計數方式變更。保留年度說明，不提供無條件跨年增減或治安排名分數。季度資料可能與修訂後年統計不同。此次官方查詢網 2025 全年為 608,717 件；較早通報為 614,843 件，採此次下載快照，保留取得時間及雜湊。修訂後 608,717 件亦可於[警政署近期月報總表](https://www.npa.gov.tw/ch/app/data/doc?detailNo=949193398038827008&module=wg055&type=s)核對。

## 地區對照

縣市＋鄉鎮名稱精確對照，以 NFKC、空白及台／臺正規化；不模糊匹配。空鄉鎮保留於縣市與全臺合計；來源不明縣市／鄉鎮組合 `999990/00`、`999990/0`、`2/空白`、`空白/空白` 只保留全臺，不猜測歸屬。新的不明代碼會阻擋建置。已審核的總量與未對照數在 `data/crime/expected-totals.json`，不能由建置自動更新以掩蓋差異。

2024／2025／2026 收錄案類總量為 26,239／36,417／19,483 件。鄉鎮未對照 2,057／43／21 件，其中縣市未對照 26／40／21 件。鄉鎮數字只包含已明列該鄉鎮的發生紀錄；沒有紀錄為來源內零件，不代表沒有任何刑案。

## 架構、更新與檢查

`src/data/crime.ts` 獨立 repository 驗證年份、範圍、期間、分類與正數人口；成功快取、失敗重試。每個範圍／期間一個靜態摘要，最多 391 筆行政區；不讀村里與逐案分片。共用 navigator 支援縣市選取及鄉鎮選取；切換成功才提交年份、資料與 URL，保留相機、搜尋與手機面板狀態。分享、瀏覽器返回、跨主題與桌面雙圖比較沿用共用路由。

```sh
npm run crime:fetch
npm run crime:build
npm run crime:check
```

`data/raw/crime/` 忽略提交；`data/crime/sources.json` 登錄 CSV、人口分頁、年月、取得日與 SHA-256。`public/data/crime/manifest.json` 列出可用快照，各年摘要附來源 URL 與雜湊。更新要先核對官方可用年月與季度、登錄網址及人口截止月份，再下載建置並審核差異。CI 的 `crime:check` 只依賴公開輸出和已審核總量，驗證 22 縣市／368 鄉鎮、案類加總、未對照數與人口加總。

色階按案類與指標設定，件數另依縣市／鄉鎮粒度；同案類／指標跨年固定，不因視角改變重分級。稀少案類使用較小切點以保留區域差異。
