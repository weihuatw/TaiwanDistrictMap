# 學區地圖（第一版：臺北市）

入口：[school.html](../school.html)。沿用行政區頁的底圖、縣市與鄉鎮市區導覽、灰色鄰區切換、清單搜尋及返回視角。

1. 全臺縣市概覽 → 選取臺北市 → 顯示行政區界。
2. 選取行政區 → 僅顯示該區學校位置與行政區虛線輪廓，不載入或描繪所有里界。
3. 選取學校 → 載入、填色該校學區對應的里界；再次選校可切換。返回先回到行政區學校概覽及原視角，再返回縣市。

國小與國中兩個 checkbox 預設勾選，可選擇其中一種或兩種皆不顯示。篩選同時作用於地圖標記與學校清單；隱藏已選學校的學制時，清除其學區。國中部與國小部各自為一筆學校／學部資料，共同校地的標記並排顯示。可搜尋校名或教育部學校代碼。

## 資料範圍

2026-10-08 建立第一版：臺北市 221 筆學校／學部位置（148 國小、73 國中），其中官方里鄰對照表內的 140 國小與 72 國中／國中部，共 212 筆全部成功對應。另有 9 筆校地資料屬於未收錄學區對照的學校，顯示「學區尚未收錄」。第一版以官方學區表內的公立學校為完整對照範圍；校地圖不是最新完整的公私立學校名錄。

其他縣市仍可沿用行政區導覽，學校層級顯示「第一版支援臺北市」，不發出不存在的學校檔案請求。

| 官方來源 | 用途 | 版本 |

| [臺北市中小學校學區](https://data.taipei/dataset/detail?id=678c5215-f14a-47e3-92bd-da43f9d7c7a9) | 學校代碼、里鄰學區、共同學區 | 115 學年度（2026-09-16更新） |
| [國土測繪中心各級學校範圍圖_121分帶](https://data.gov.tw/dataset/174606) | 校地內部代表點，非校門定位 | 1150409 |

學區年度與校地／里界版本分開記錄。只要某里有部分鄰屬於學區，即填色完整里界；保留「部分鄰」與「共同學區」註記，不將整里填色解釋為全里都屬於該校。共同學區中的學校亦納入對照，不用距離、鄰近學校或 Voronoi 推估學區。學區跨行政區或跨到新北市時，依官方表的縣市、行政區、里名連接，載入所有相關行政區的里檔案。

校地以縣市與正規化名稱去重，多片校地取面積最大的校地之內部代表點，再與鄉鎮市區界作空間對照。校名的「國民小學／國小」「國民中學／國中」與實驗學校簡稱統一比對；區分公私立，模糊或重複比對不任意選取。北市大附中按[臺北市官方更名公告](https://www.gov.taipei/News_Content.aspx?n=F0DDAF49B89E9413&s=CA809735D070BB53)對應原大理高中校地。官方表中的「市立?公國中」「糖?里」明確對應「瑠公」「糖廍」，別名與補充座標皆記錄於 `join-report.json`。

## 重建與驗證

```sh
npm run school:fetch
npm run school:build
npm run school:check
npm test
npm run build
```

下載流程使用 Python 3、curl；校地轉換沿用專案的 Mapshaper，空間比對使用現有 Turf，不需新增套件。原始下載位於已忽略的 `data/raw/school/`，來源、下載日期及 SHA-256 保存於 `data/school/sources.json`。更新資料前請核對官方下載連結與學年度。

公開產物位於 `public/data/school/`：

- `towns/{TOWNCODE}.json`：12 個臺北市行政區的學校及學區對照，依需求載入與快取。
- `manifest.json`：來源、資料版本、收錄範圍、數量及限制。
- `join-report.json`：學校／里對照缺漏、明確別名及補充位置紀錄。

資料檢查核對學校點位是否在該行政區、代碼唯一性、資料數量、全部學區里代碼與名稱、跨區對照，以及資料來源。導覽測試涵蓋學校層級不載入全部里、返回與保存視角、空篩選、取消已隱藏學校、跨區學區、請求競態、失敗重試與頁面清理。

應用位於 `src/apps/school/`，由獨立 `SchoolNavigator` 管理第三層學校與選校狀態；`polygonView()` 將學區幾何轉成共用圖層資料，不修改現有行政區快取或行政區／所得頁的導覽行為。共用 shell 僅增加可選的主題清單 renderer；其他頁面沿用原本預設清單。
