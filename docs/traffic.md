# 傷亡交通事故地圖

入口 `#/traffic`。可切換事故件數、受傷人數、死亡人數及每十萬戶籍人口事故件數，年份、指標與行政區路徑保存在 hash query。全臺只顯示行政區色階；選縣市後載入該縣市事件，鄉鎮與村里依歸屬代碼篩選。資訊面板可勾選「顯示事件位置（小圓點）」，預設開啟；關閉時只隱藏點位與事故彈窗，區域色階及統計保留。選項沿用年份／區域切換，分享網址以 `points=hide` 還原隱藏狀態。事件使用 MapLibre circle 圖層，點選可查看時間、官方地點及死傷數；紅色表示死亡事故，橘色表示其他傷亡事故。選擇死亡人數指標時，事件圓點只顯示 A1 且至少 1 人死亡的案件；其他指標仍顯示目前範圍內全部有座標案件。

## 來源與統計口徑

- [警政署 113 年傷亡道路交通事故資料](https://data.gov.tw/dataset/172969)：2024 全年。
- [警政署 114 年傷亡道路交通事故資料](https://data.gov.tw/dataset/177136)：2025 全年。
- [即時 A1](https://data.gov.tw/dataset/12818)、[即時 A2](https://data.gov.tw/dataset/13139)：2026 更新中。
- 授權為政府資料開放授權條款第 1 版。原始下載網址、取得時間、大小及 SHA-256 保存於 `data/traffic/sources.json`；原始 CSV／ZIP 位於忽略提交的 `data/raw/traffic/`。

只收錄 A1／A2 傷亡事故，不含純財損 A3。官方逐案檔每個當事人各一列；以 `當事者順位=1` 計算每案一次，事故層級的 `死亡受傷人數` 也只加一次。不保存當事人的年齡、性別、車種等欄位。死亡數是公開檔案的 24 小時口徑，不能冒充交通部 30 日死亡數。

2026-10-13 取得之 A1 最後事件為 10 月 5 日，A2 最後事件為 9 月 17 日。兩類只取共同、已結束且逐月連續的月份，故 2026 目前使用 1–8 月，並排除 9–10 月的 11,895 筆事件。不可把更新中年度當作全年，也不年化。

2024／2025 發生率分母沿用 `public/data/population/annual/{year}/` 的兩年底平均戶籍人口；村里缺少任一年底人口時為無資料，不補零。2026 分母使用 2026 年 8 月戶籍人口。上層先加總件數再除人口，不平均下層發生率。這是發生地事故數與戶籍人口的比較指標，包含外地用路人，不能解讀為居民個人的事故機率。

## 空間歸屬與缺漏

官方座標以現有國土測繪中心展示界線做 point-in-polygon；村里使用 1150817 版，並非事故當年的歷史界線。先取唯一村里，沿其代碼確定鄉鎮與縣市。邊界命中多個村里時，僅能由官方地點明確記載的鄉鎮縮小至唯一候選，否則留白。村里無法對照時再查鄉鎮、縣市圖形，最後以官方地點的精確縣市＋鄉鎮前綴確認上層；不模糊比對，不以最近村里補值。

無效座標仍納入能確認的行政區統計，但不建立事件點位。座標判定的縣市／鄉鎮若與官方地點的精確縣市／鄉鎮前綴衝突，該座標不可信：僅計入地址可確認的上層統計，村里留白且不發布事件圓點，不猜測替代座標或最近村里。地址只有縣市時，不推定鄉鎮；未辨識到精確地址前綴時，仍按唯一幾何命中處理。邊界多重命中可由地址縮小至唯一村里，不視為衝突。

沒有村里對照的事件留在上層，村里加總與上層之間的差額保存在 `join-report.json`。`invalidCoordinates` 是無效／缺失座標，`rejectedCoordinates` 是地址／座標行政區衝突，兩者分開統計；`coordinateConflictsByVillage` 記錄原先座標會落入各里的衝突件數。`unmatched.json` 保存原因、原始座標及原幾何命中的代碼供追查。未編定範圍的合法幾何也保留，缺人口分母時發生率為無資料。

其他衝突集中的村里包括中和中原里（2026：253 件）、新竹縣寶山鄉大崎村（2024：166 件）、高雄市橋頭區橋頭里（2025：175 件）。全部採相同規則處理；衝突可能包含界線誤差，不能將所有衝突一概認定為官方地址正確或座標錯誤，但足以停止發布其精確點位。全臺事故與死傷總數不變，上層行政區按可確認地址重新計算。

重建後全部公開事件點位與可辨識地址的縣市／鄉鎮衝突為 0。這項檢查無法辨識同一鄉鎮內的錯誤座標或缺少明確行政區的地址，故不能保證剩餘每一點的位置正確；不利用案件數高低直接刪除資料。

## 更新與驗證

```sh
npm run traffic:fetch
npm run traffic:build
npm run traffic:check
```

更新前先查核政府資料開放平臺的資源網址、年度及可用月份；來源固定登錄，不自動猜測下一年度。fetch 保留原始檔，若需要更新即時檔，先保存舊快照後替換對應原始檔並更新取得日。parse 驗證 SHA-256、年份、日期及死傷欄位，不把未知欄位轉零。

公開輸出：每年 `manifest.json`、`national.json`、`counties.json`、`towns/{county}.json`、`villages/{town}.json`、`events/{county}.json.gz`、`join-report.json`、`unmatched.json`。全臺概覽不下載事件分片。摘要與事件的成功結果按年份快取，失敗不快取；導覽沿用共用請求序號，事件更新等待相機停止，導覽期間隱藏舊點位，清理時取消排程、事件與 popup。

`traffic:check` 僅讀公開資料，驗證所有事件 ID 唯一、年份／座標／上層代碼、點位數、村里死傷總數，以及各層加總加未對照差額等於上層總計；另檢查發布點位的行政區與可辨識官方地址一致、所有排除座標未發布為點位、排除原因及各里衝突件數與報告相符。CI 不需原始 CSV。前端與解析回歸在 `tests/traffic*.{mjs,py}`。
