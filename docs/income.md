# 2024臺灣所得地圖

入口：[income.html](../income.html)。本機開啟 `http://127.0.0.1:5173/income.html`；`index.html` 保留原本的行政區瀏覽。

所得頁共用 `src/map-core/` 的導覽、相機及行政區互動，採 TomTom `monoLight` 向量底圖，讀取既有 `.env.local`。所得與幾何分別載入，按官方行政區字串代碼連接。前端不向財政部網站即時請求資料。

## 官方資料與指標

資料：[113年度綜合所得稅申報初步核定統計專冊](https://www.fia.gov.tw/singlehtml/43?cntId=4c3fc1e8a7c545179280b6a50a27cd35)。所得年度2024，發布日期2026-06-30；以官方 HTML 壓縮檔取得，狀態固定標示為「初步核定」。

- 縣市：表6-1的綜合所得總額除以納稅申報戶數。
- 鄉鎮市區：表165的官方「合計」。若合計缺漏，才用各村里所得總額與戶數加權彙整。
- 村里：表165的村里資料列。
- 全臺首頁：22縣市的綜合所得總額合計除以其戶數合計。

各層都採「綜合所得總額」，不混用表8-1「總所得」或「所得淨額」。原始金額為千元；呈現為萬元／申報戶／年，保留一位小數。平均依所得總額／戶數計算，原始報表的平均數也保存以利核對。中位數只採該層官方資料，沒有平均下層中位數。

本項統計不含免稅、分離課稅與非課稅所得，不能當作個人薪資或可支配所得。

## 界線年度與對照

使用現有官方界線：縣市與鄉鎮市區為1140318，村里為1150817。2024所得與現行界線不完全一致，以縣市＋鄉鎮市區＋村里完整名稱對照，未採模糊比對或任意分攤。

財政部 HTML 的特殊造字與國土測繪中心的方括號字形記號，使用明列的字形正規化。正規化後的名稱必須在同一個行政區內唯一，並記錄原始名稱。更名、拆分、合併等差異不當作字形差異處理。

目前對應22縣市、368鄉鎮市區及7,734村里。另有46個現行具名村里未對應及206個未編定範圍，顯示斜紋「無資料」，不使用零所得。對應村里的申報戶數涵蓋22縣市申報戶的99.76%。

官方「其他」統計仍納入其上層總額；它不等同未編定村里 polygon，沒有將其平均值分配給那些圖形。瑪家鄉三和村補充界線仍依原有資料政策保留、不混入全國主圖層。

[完整對照與加總核對紀錄](../public/data/income/2024/join-report.json)記錄未對應名稱、缺資料界線、字形對照與22縣市的總額核對。

## 配色與操作

七階固定級距：未滿55、55至未滿65、65至未滿75、75至未滿90、90至未滿110、110至未滿150、150萬元以上。切點參考2024村里平均所得的實際分布，但全國、區及里都用同一組金額切點，不因縮放重新分級。

固定38%填色透明度；滑過與選取不改變透明度，只強調輪廓。其他縣市與同層鄰區維持灰色並可切換，資料缺漏另用斜紋。清單依目前層級平均所得排序；點村里顯示平均、中位數、戶數與相對上層的差異。

## 資料流程

```sh
npm run income:fetch
npm run income:build
npm run income:check
```

- 原始官方 ZIP：`data/raw/income/113/source.zip`，已忽略、不提交。
- 來源、SHA256及版本：`data/income/sources.json`。
- 公開資料：`public/data/income/2024/`，含 `counties.json`、按父層分檔的 `towns/` 與 `villages/`、`manifest.json`、`join-report.json`。
- 整理腳本：`scripts/income/`，只需要Python標準函式庫；下載使用curl且保留TLS驗證。

HTML報表有嵌套表格，解析器保留內層鄉鎮名稱與外層第一筆村里資料。村里合計對鄉鎮戶數、鄉鎮合計對縣市戶數都要求一致；所得總額容許官方千元整數呈現造成的微小捨入差。

重新建置界線不會刪除所得等主題資料；界線版本更新後，應重新執行所得整理與檢查。資料重建後重新整理瀏覽器，以清除該頁的載入快取。

## 驗證

```sh

npm run data:check
npm run income:check
npm run build
```

測試包括所得資料路徑、快取、失敗重試、錯誤年度／父層拒絕、零戶數、級距邊界、嵌套HTML解析及現有導覽。所得資料檢查涵蓋全部輸出代碼與父子關係、平均值公式及22縣市原始總額核對。
