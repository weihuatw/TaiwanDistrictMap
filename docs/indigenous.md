# 原住民人口地圖

原住民主題使用 `#/indigenous`，固定展示 2026 年 8 月戶籍統計。地圖可切換人口數與占同地區、同月份總戶籍人口比例，並從當期資料欄位選擇所有族群或單一族群。比例以上層加總後的族群人數除以總人口計算。戶籍統計不代表實際居住分布，也不代表法律認定狀態。

主要分子來源是內政部戶政司 ODRP018「現住原住民人口按性別、身分、原住民族別分（新增區域代碼）」；分母使用同月 ODRP014 公開人口快照。行政區用代碼連接，不以名稱模糊配對。11508 有 7,781 筆來源列，含 26 個族別欄位；西拉雅族 40 人，數個族別雖為 0 仍會列入選單。三和村 `10013280006` 有官方統計但沒有主圖層界線，保留於鄉鎮以上彙總。來源名稱與界線名稱有 23 筆差異，見輸出 join report。

資訊面板的「各民族人口數」區塊可收折，依目前顯示的全臺、縣市、鄉鎮或村里範圍列出 26 個族別人數。官方明列為 0 的族別顯示 `0 人`；「尚未申報族別」另外列示並註明不是民族選項。切換區域、指標或地圖族群選單時，明細區塊的開啟狀態保留。

一般前端開發使用已提交的 `public/data/indigenous/`。若更新月份，先從官方 API 取得每一頁，檢查回應月份、頁數、總筆數及欄位後再建置。分子與分母必須使用完全相同的月份。原始分頁保存在忽略提交的 `data/raw/indigenous/<民國年月>/`，SHA-256 登錄於 `data/indigenous/sources.json`。

```sh
npm run indigenous:fetch -- 11508
npm run indigenous:build -- 11508
npm run indigenous:check
```

`data/indigenous/tribes.json` 是明列的欄位登錄；遇到新增或移除欄位時先核對來源再更新登錄。`expected-exceptions.json` 保存已審核的無界線代碼與名稱差異數，檢查程序不會自動接受覆蓋率退步。公開檢查只讀輸出，不需要原始下載。
